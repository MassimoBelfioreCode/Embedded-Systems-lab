# Embedded-Systems-lab
Hands-on firmware development practice using STM32 microcontrollers.

**STM32 NUCLEO BOARDS**: NUCLEO-F401RE, NUCLEO-L476RG

**MCUs**: STM32F401RE, STM32L476RG

**Core**: ARM Cortex-M4

Programming Language: C

N.B. The firmware uses CMSIS together with a custom library developed for the course (stm32_unict_lib.h) to interact with the hardware.
